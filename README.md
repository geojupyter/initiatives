# GeoJupyter initiatives

This repository acts as a "roadmap" for the GeoJupyter community.

The reason this repository exists is to enable roadmapping as a living discussion, not a
static artifact.


## Authoring effective initiatives (mindset)

Writing initiatives may require adopting a mindset that doesn't come naturally to you.
These tips are intended to help you get in to the right mindset.

Your job as an initiative author is _not_ to advocate for a specific idea.
Your job is to instead _characterize an opportunity clearly enough that the community
can compare it to other opportunities and decide whether (and when) to pursue it_.

Try imagining yourself reading your answers to each question out loud to another person,
and then imagine them asking follow up questions.
If they can't understand what you said in your answer (and the detail isn't in another
section) then you have to go back and clarify.

When filling out specific fields, carefully read the field descriptions in the GitHub
template.
They are written to help you get in to the right mindset!

## Information management

The roadmap is managed as GitHub issues.


### Labels

Labels are used to categorize and prioritize the issues.


### Issue structure

This repository includes a "linter" (in the `validator/` directory) for those issues
which ensures each issue provides necessary details for us to effectively plan each
initiative.


### Project board

The
[GeoJupyter Initiatives Project Board](https://github.com/orgs/geojupyter/projects/6)
gives us an interface to visualize issues.
This is a work in progress.
